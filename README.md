# ProiectareaAplicatiilorWeb

Proiectare aplicație Android: Dezvoltarea unei biblioteci virtuale de cărți inspirată de platforma Goodreads.

Integrare API-uri: Utilizarea unor servicii externe pentru preluarea automată a detaliilor despre cărți, coperți și recenzii.

Funcționalități: Gestionarea lecturilor personale, organizarea pe rafturi virtuale și urmărirea progresului de citit.

Obiective propuse: 

Dezvoltarea interfeței mobile: Crearea unei aplicații intuitive pentru Android/iOS folosind un framework modern (ex: Flutter sau React Native).

Gestionarea cărților: Implementarea unei funcționalități de căutare, vizualizare detalii și adăugare a cărților în bibliotecă.

Sistem de recenzii și rating: Posibilitatea utilizatorilor de a lăsa note (stele) și recenzii pentru cărțile citite.

Urmărirea progresului lecturii: Crearea unui profil unde utilizatorii își pot marca starea cărților (citite, în curs, de citit).
